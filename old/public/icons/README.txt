# Large Professional SVG Icons

All SVGs are preserved as vector artwork and configured with a 512x512 default display size
for better visibility when used directly on a website. The original viewBox/aspect ratio is
preserved, so the artwork remains sharp at larger sizes.

Recommended CSS:
.icon { width: 96px; height: 96px; }
or use Tailwind: w-24 h-24, w-28 h-28, etc.
